## Как запустить за 1 клик:
1. Убедитесь, что у вас установлен и запущен **Docker Desktop**.
2. Распакуйте этот архив в любую папку.
3. **На Windows:** Дважды кликните на файл `START_FLATAI_WINDOWS.bat`.
4. **На Mac/Linux:** Запустите `chmod +x START_FLATAI_MAC_LINUX.sh && ./START_FLATAI_MAC_LINUX.sh` или выполните `docker compose up --build` в терминале.
5. Откройте в браузере:
   - Дашборд нейронки: http://localhost:8000
   - Документация API (Swagger): http://localhost:8000/docs
